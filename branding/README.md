# Talk2Society channel logo assets

Official Talk2Society logo artwork supplied by the channel owner. Use these existing logo assets in future videos rather than recreating the mark:

- `talk2society_logo_primary.png` — primary close-cropped logo artwork.
- `talk2society_logo_variant.png` — alternate close-cropped logo artwork.
- `talk2society_logo_black_background.png` — square version with black canvas and extra surrounding margin.

Preserve the source artwork and aspect ratio. For video overlays, scale proportionally and place where it does not obscure scene content; use the black-canvas version only where that background suits the composition. These files were added for future productions and do not modify the already-built TV10 video.
