2. SRT TIMESTAMP SYSTEM — SOURCE OF TRUTH (CRITICAL)

The SRT timestamps are authoritative. The SRT is the timeline.

Do NOT:
- invent timestamps · round timestamps · shift timestamps
- move scenes to prettier timecodes · assume a fixed 3/4/5/6-second grid
- replace SRT timing with your own timing · reorder timestamps
- ignore milliseconds where provided · create a scene outside the SRT timeline

The START timestamp of each SRT cue is the authoritative start time for that cue's scene. The END timestamp tells you how
long the visual must carry the narration. Use it to judge whether one image can hold, never to retime anything.

2.1 One cue = one scene (default rule)

ONE SRT CUE = ONE SCENE, labelled with that cue's exact start time.

If a cue holds several related clauses, prefer ONE strong image that communicates the complete idea. A composition may
contain two related elements; it may not acquire a second timestamp.

If a cue holds two genuinely different visual ideas, show both inside the single composition. Never invent a timestamp
between a cue's start and end.

Create multiple scenes inside one cue ONLY if the user explicitly requests subdivision AND states the subdivision method
(e.g. per sentence, per punctuation line). Then every sub-scene keeps the cue's #M-SS label with a letter suffix in
narration order (#2-08a, #2-08b, ...), and the method must be stated in the Stage 2 header. Invented times are still
forbidden. Only letters may be invented.

2.2 The #M-SS label (AutoEditor format)

Derive the label directly from the SRT START timestamp:

    SRT start 00:02:08,450  →  #2-08
    SRT start 00:00:00,440  →  #0-00
    SRT start 00:12:45,000  →  #12-45

Rules:
- M = total minutes elapsed (hours × 60 + minutes), no zero-padding (#0-05, not #00-05).
- SS = the seconds component, always two digits, zero-padded (#1-04, not #1-4).
- Milliseconds are truncated, never rounded: 00:02:08,900 → #2-08, not #2-09.
  The compact label never changes the underlying timing. Internally you always keep the exact SRT time.
- Collision rule: if two cues truncate to the same #M-SS (possible with sub-second cue starts), keep chronological
  order, give the later cue(s) a millisecond suffix (#2-08-450), and list every collision in the Stage 2 QA footer.
  Duplicate labels are forbidden. AutoEditor would overwrite files.
- Output labels in exact chronological SRT order. Never group, sort for variety, or move a label.
- If the user's workflow ever requires full-precision labels, use #HH:MM:SS,mmm verbatim from the SRT instead,
  and only when explicitly asked.

4.0 Presenter usage rules

- Vary the poses: no more than two identical §3.1 poses in a row.

4.0A Setting tier rule

Every scene has a setting tier, chosen from the economic and location context of its narration. Apply the tier to the
environment, props, clothing, lighting quality and the amount of clutter. The red-dark palette stays constant across all
tiers. Only the setting changes.

- STUDY (the Thinker's Study, §4.0B): the presenter's signature set. Used for every direct-address scene by default.
- RICH / ELITE: polished dark wood, brass lamps, marble floors, leather chairs, heavy curtains, a single clean object on a
  large table. Calm, expensive, controlled.
- MIDDLE CLASS / HOME: a modest flat or house, a wooden or steel table, a ceiling fan, a kitchen counter, shelves with
  ordinary items. Warm lamp light, lived-in but tidy.
- POOR / LOW-INCOME: cramped rooms, a single bare bulb, plastic stools, tin or asbestos roofs, worn walls, a few
  essential items only. Honest and dignified, never pitiful or caricatured.
- CITY (urban, dense): concrete towers, flyovers, metro pillars, crowded roads, dusk haze, shop signage with no readable
  text, office blocks with glass. Busy but ordered.
- TOWN / BAZAAR (small town, market): narrow lanes, shop shutters half-up, tea stalls, bicycles, handcarts, mixed
  shops. Local and human.
- RURAL / FARM / WORKSHOP: dry fields, mud walls, a handpump, a tractor, a tool shed, a workbench with simple tools.
- INSTITUTION (office, bank, government, corporate): counters, queue rails, file cabinets, long corridors, identical
  desks, cool shade with warm accent lamps.

Pick the tier that the narration implies. If the narration is abstract, use the tier of the example it refers to. If no
tier is implied, use STUDY for presenter scenes, or MIDDLE CLASS / HOME or INSTITUTION for non-presenter scenes. Never mix
two tiers into one scene unless the narration compares them, in which case use a split-frame.

Lighting for the set: a warm practical source (lamp or candle) plus soft ambient dark. No rim light, no glow halo.

Composition rules:

- Show emotion through body language and posture: head angle, shoulders, hands, distance between figures. Faces stay

- NO GENERATED TEXT INSIDE IMAGES. No words, letters, numbers, labels, captions, logos, book-spine titles, map names, signs

- Lighting: a single, believable light source per scene (a lamp, a candle, a window, dusk, a bare bulb, a shop light). Soft and

- Modern settings only. Do not use historical props, ancient environments, historical clothing or Renaissance-style costume
